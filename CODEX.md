# Mappa Squadra — istruzioni per Codex

Le regole del progetto sono ora **condivise tra Codex e Claude** e stanno in un
unico file: **[`AGENTS.md`](AGENTS.md)**. Leggere quello.

Conteneva prima le istruzioni complete, che sono state spostate in `AGENTS.md`
senza perdere nulla — obiettivo, vincoli, file principali, identità del
partecipante, criteri di accettazione e sviluppi possibili sono tutti lì, più
quanto si è scoperto leggendo il codice. Il testo originale resta nella storia
di git (primo commit, `66a174b`).

**Le modifiche alle regole vanno scritte in `AGENTS.md`, non qui**, altrimenti
Claude non le vede: due file di istruzioni che divergono sono esattamente il
problema che questa struttura evita.

Prima di iniziare un intervento, leggere anche `HANDOFF.md`: è il registro di
cosa ha fatto l'altro agente e di cosa è rimasto aperto.
